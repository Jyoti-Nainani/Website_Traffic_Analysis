# Website Traffic Analysis #
A systematic website performance analysis. 
## Objectives of the Analysis: ##

- Trends in website sessions and users over time.
- Biggest contributor Marketing Channel in terms of volume of users.
- User Behaviour and Content Effectiveness.
- Variation in traffic across Channel.
- Performance variation in engagement across different marketing channel.
- High traffic hours on website.
- Correlation between high traffic and high engagement rate.

  ## Tool used: ##
Python| Jupyter Notebook| Pandas| Numpy| Matplotlib| Seaborn
